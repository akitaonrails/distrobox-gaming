# Forza Motorsport 4 — PC port (hl360-forza4)

[0herculabs/hl360-forza4](https://github.com/0herculabs/hl360-forza4) `v0.3.9`
is a native recompilation of the Xbox 360 game with ReXGlue, run through
GE-Proton. It **replaced `Alexbeav/fm4-recomp` on 2026-10-27**: that project
only ever accepted the *Europe* Game of the Year disc, while this one supports
the **USA Rev 1** play disc, and it ships an **SDL3/Dear ImGui launcher**
(no WebView2, so it works under Wine) with disc installation, Project Forza
Plus 4 support, wheel FFB and named profiles. v0.3.9 switched the renderer to
**Vulkan**, which fits this box's setup.

## Supported discs (exact)

| | |
|---|---|
| Title ID | `4D530910` |
| Media ID | `33E7B39F` |
| XEX version | `0.0.0.14` |
| Disc 1 — Play Disc, **USA Rev 1** | 8,738,846,720 B · MD5 `2470358250b8566bf5ddc3aaf1b76c68` |
| Disc 2 — Content Install Disc, **USA Rev 1** | 8,738,846,720 B · MD5 `9915d1adaabf3b58441651a70e5e8dbe` |

Other regions and revisions are unvalidated by upstream and refused by its
installer (full-ISO MD5, then a SHA-256 manifest of the extracted files).

**Local status: both discs present, neither matching.** The library holds the
USA *original* print — Disc 1 `cca0bf793e0e4086987359260054851e` (= redump
79785, not Rev 1) and Disc 2 `f50603eec0b6c6e058d84539e35d51ef`. So the port is
installed and its launcher runs, but **the game itself still needs the USA
Rev 1 (2012 "Racing Game of the Year") play disc**, which is the US twin of the
EU Rev 1 disc the previous project required. The role prints the mismatch on
every run.

## Run

Walker entry **Forza Motorsport 4 · PC Port** → `bin/fm4-port` → `fm4-launcher.exe`
under GE-Proton. The launcher's **Install** tab takes Disc 1 (step 1) and Disc 2
(step 2), then Profiles → Play. Player data (profiles, settings, extracted game,
logs) lives in `~/.local/share/hl360-fm4`, symlinked into each release, so
version bumps keep saves.

## Notes and expectations

- **60 FPS is the recommended target.** The 120 FPS mode is experimental and
  upstream warns it produces visual artifacts; it also needs a 120 Hz desktop,
  which the launcher does not set.
- Graphics presets Low/Medium/High/Custom, 1x–4x internal resolution, 16x AF,
  FXAA/FXAA+, FSR or CAS output scaling; guest video stays 720p internally.
- Project Forza Plus 4 (the community career/car mod) can be installed from the
  same launcher; uninstall preserves saves.
- Wheel support is a headline feature (guided binding from any USB device, the
  game's own FFB effects, SimHub telemetry). Controller support is SDL/XInput.
- Xbox Live features are not provided; profiles are local.
