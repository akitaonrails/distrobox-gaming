# Sonic 2 (2013) + the "Sonic 2 Mania" mod

`install_sonic2_2013` (`install-sonic2-2013.yml`, `site.yml --tags sonic2_2013`)
builds the [RSDKv4 decompilation](https://github.com/RSDKModding/RSDKv4-Decompilation)
natively in the box and runs **Sonic the Hedgehog 2 (2013)** with the
GameBanana **"Sonic 2 Mania"** mod.

The mod (`sonic_2_mania_9e646.zip`) targets Sonic 2 (2013), *not* Sonic Mania.
`Data.rsdk` is extracted from the user's Android XAPK (the game data lives at
`assets/Data.rsdk.xmf` inside `com.sega.sonic2.runner.apk`). The data-only mod
goes in `mods/` and is enabled via `mods/modconfig.ini`.

**Two gotchas baked into the role:**
- `modconfig.ini` values must be **`true`** (or `1`) — the RSDKv4 IniParser's
  `GetBool` rejects `y`, so `Sonic 2 Mania=y` silently leaves the mod inactive
  (the game plays as stock Sonic 2). Use `Sonic 2 Mania=true`.
- `settings.ini` seeds **`VSync=false` + `RefreshRate=60`** — on the 240 Hz
  DP-1, VSync ties the engine tick to the display and the game runs ~4× fast
  (the ini's own comment warns "the engine is built around running at 60 FPS").

Launcher `bin/sonic2-2013`, Walker **"Sonic 2 (2013) + Sonic 2 Mania"**,
fullscreen on DP-1, 8BitDo native. Toggle stock/modded by editing the
`=true` line in `mods/modconfig.ini`.

## Parked: Sonic Megamix Mania (2026-09-05)

Megamix is a **DLL code-mod for Steam Sonic Mania** (its `mod.ini` `DLLFile=`
lists 24 native DLLs that *are* the characters), not a data mod. It was
**installed, diagnosed, and removed** — the Steam Sonic Mania dir was restored
(run Steam → Verify Integrity for a pristine restore), the native Mania decomp
and the Megamix/vanilla launchers were deleted, and the `584400` launch option
was dropped. The downloads stay on the NAS
(`ROMS_FINAL/PC/sonic remake/`: the Megamix rar, `ManiaModLoader.7z`).

**It CAN run on Linux/Steam Deck** — there's a working method
([GameBanana tut 19468](https://gamebanana.com/tuts/19468)); Megamix Mode has
been completed on Deck. The correct method (which our headless shortcut did
**not** follow) is:

1. **ProtonTricks** + install the **offline .NET Framework** into the Sonic
   Mania Proton prefix (`right-click the .NET installer → open with
   ProtonTricks → select the Sonic Mania prefix`). This is what lets the
   manager run — our attempt skipped it (the `.NET` ManiaModManager GUI won't
   start under wine-mono).
2. Extract the **Mania Mod Loader** into the game dir and **Megamix into
   `mods/`** (this part our role did).
3. Run **ManiaModManager.exe via ProtonTricks** in the Sonic Mania prefix,
   select the Megamix mod, "Install loader", save.

Our headless approach (copy `ManiaModLoader.dll` → `d3d9.dll`, write
`ManiaModLoader.ini` by hand, `WINEDLLOVERRIDES="d3d9=n,b"`) got all 24 DLLs to
load and version-match (`GameVersion 5 == GameVer 5`), and the data mods
applied, but the characters rendered as placeholders — the manager-driven
setup (with .NET) is the reliable path. To un-park: follow the three steps
above, ideally scripted with `protontricks -c` for the .NET install.
