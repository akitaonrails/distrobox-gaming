# Sources & downloads

Upstream sources for the **native ports, recompilations, decomps, fan games and
ROM-hack tooling** this repo installs — one place to check what each thing is and
where it comes from, if you want to grab a build yourself.

The playbooks fetch these automatically (some are pinned by version/sha and
NAS-staged); this page is just the provenance. **No ROMs, BIOS, keys or game
data are provided or linked here** — recomps and hacks need your own legal dump.
`[doc]` links the detailed write-up we keep for each.

## ROM hacks & patches

The `install_rom_patches` role applies IPS/BPS/xdelta patches over your own
dumps; the SNES/Genesis/GBC hacks in the library are patched ROMs you supply.
Patch files are **not** committed — grab them from the sites below.

| What | Where to get patches |
|---|---|
| Data-driven IPS/BPS patcher (role) | [doc: rom-patches.md](rom-patches.md) · [how-to: rom-hack-patching.md](rom-hack-patching.md) |
| N64 Kaze hacks (e.g. Return to Yoshi's Island) | [RomHacking.com Discord / RHDC](https://www.romhacking.com/) |
| SNES hacks (SMW, Zelda, Metroid, …) | [SMW Central](https://www.smwcentral.net/) · [RHDN](https://www.romhacking.net/) |
| DKC GBA colour restoration (marc_max) | [RHDN](https://www.romhacking.net/) |
| Naming hacks cleanly in ES-DE | [doc: esde-romhack-names.md](esde-romhack-names.md) |
